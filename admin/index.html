Curated SwoopTV catalogue

Each listing can contain multiple provider stream IDs. The first is primary, the rest are backups. Move listings up/down and between curated categories. Drag a source item onto a category to add it.

EPG Sources & Channel Matching

Import an XMLTV guide file to match Australian and international channels to your curated Live TV catalogue. Matching uses XMLTV IDs, cleaned channel names and aliases. Review unmatched channels before exporting. Provider short EPG remains the first source in SwoopTV.

Trakt / MDBList imports

Import movie or TV lists, compare against your imported Xtream catalogue, and curate only available titles. Import your provider playlist first. Keys are used for requests only and are not saved in the draft.

Matching names and years are accepted automatically. All matching provider sources are retained, with English prioritised. A series match confirms a provider series entry, not individual episode availability. API requests depend on each service's browser access policy.
